# وش أطبخ — دليل النشر على Vercel

## الملفات
- `public/index.html` — واجهة الموقع (نفس اللي جربته، مع تعديل بسيط يخليها تكلم السيرفر)
- `api/generate-recipe.js` — الجزء الخلفي (Serverless Function) اللي يتصل بـ Anthropic API بمفتاحك بأمان
- المفتاح نفسه **ما ينحط بأي ملف** — ينضاف كمتغير بيئة سري من لوحة تحكم Vercel

## خطوات النشر (~10 دقائق، بدون خبرة برمجة سابقة)

1. **سوّي حساب على vercel.com** (تقدر تسجل بحساب GitHub مباشرة، مجاني)
2. حمّل هذا المجلد كامل، وارفعه لمستودع جديد على GitHub (أو اسحب المجلد مباشرة داخل Vercel لو يدعم الرفع المباشر)
3. من لوحة Vercel: **Add New → Project** واختر المستودع
4. قبل الضغط على Deploy، روح لقسم **Environment Variables** وأضف:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Value:** المفتاح اللي أخذته من platform.claude.com (يبدأ بـ `sk-ant-`)
5. اضغط **Deploy** — بعد دقيقة أو دقيقتين يعطيك رابط مباشر شغال (مثال: `wesh-atbakh.vercel.app`)
6. افتح الرابط وجرّب — الزر الحين يتصل بالذكاء الاصطناعي الحقيقي عبر مفتاحك

## نصائح مهمة

- **حدد سقف إنفاق** على حسابك بـ platform.claude.com (Settings → Limits) عشان ما تتفاجأ بفاتورة لو صار استخدام غير متوقع
- الموقع مصمم يرجع تلقائيًا لقائمة الوصفات المحلية لو صار أي خلل بالاتصال بالذكاء الاصطناعي — يعني الموقع ما يتوقف عن الشغل حتى لو صار عطل مؤقت
- لو تبي دومين خاص فيك بدل رابط vercel.app، تقدر تربطه من إعدادات المشروع بـ Vercel (Settings → Domains)
